# LOSS OF SIGNAL

LOSS OF SIGNAL is a first-person, PS1-style horror game for the desktop browser, set on the Apollo 11 flight. It is built with React, three.js and TypeScript, and is an entry for Kiroween 2026.

## Commands

| Command | Does |
|---|---|
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Type-check and build to `dist/` |
| `npm run preview` | Serve the built app |
| `npm run test` | Run the Vitest tests |
| `npm run lint` | ESLint on `src` and `scripts`, then `tsc --noEmit` |
| `npm run check-budget` | Check bundle sizes in `dist/` (run after `build`) |
| `npm run check-copy` | Check the text in `src/content/` |
| `npm run e2e` | Browser smoke test, see `e2e/README.md` |
