# Reference screenshots

Taken from the earlier build of this game at 1280x720, headless Chromium with SwiftShader, `?debug` on (the green stats box at the top left is the debug overlay, not part of the game).

- `play-*.png`: one full run from the title screen to the archive, in order (act 0 to act 5).
- `ref-menu-*.png`: warning, headphones, title, chapters and settings screens.
- `ref-act3-<checkpoint>.png`: act 3 at each checkpoint (start, wp0 to wp3), 4 s after load.
- `ref-act5-tNNs.png`: act 5 every 9 s from load (re-entry, parachutes, splashdown, recovery, end).
- `ref-chapter-card.png`: act 0 just after the chapter card faded.

`play-act2-sleep.png` is black on purpose (eyes closed). `play-act4-liftoff.png` is a fade to black.
