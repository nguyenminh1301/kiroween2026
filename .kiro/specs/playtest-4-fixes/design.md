# Design: playtest 4 fixes

1. `PANEL_AHEAD` (1.08 m) in `procgen/cabin/layout.ts` replaces 0.7. The spots move with the panel. Reach stays at 2.5 m, enough for the DSKY at about 1.2 m. The layout test projects the four corners with a 60 degree, 16:9 camera at the start pitch.
2. A pure `entrySound.ts` in act 5 maps shot time to levels (rumble, roar, crackle, muffle) from the glow curve in `entryFx.ts`. The runtime applies the levels each frame to looping synth voices from the audio engine.
3. Lines become `LineSegments` (one pixel, transparent). Counts, confluence height and drogue proportions are pure data in `chutes.ts`.
4. The subtitle shows the full line with the unrevealed letters transparent (same layout), so the text stays put.

Task 4 note: the cause was the vertical line-clamp box, which made the typed and the hidden spans two separate centred blocks. Both are now one inline span. There is no DOM test environment, so this has no unit test.

5. Cause of the mismatch: the task 1 test projected only the middle panel (one of seven, 0.6 m wide), while the console arc built from seven 0.6 m panels was about 3.8 m wide, nearly twice the real console (about 7 ft by 3 ft, Smithsonian, "Instrument Panel, Trainer, Command Module, Apollo"). The outer panels projected far outside the frame. The act 5 picture came from focus turns: `CMP_HEAD` was set at the player's own couch, so "There goes the radio" turned the view down into the lap and the commander's arms. Fix: `CONSOLE_SCALE` 0.55 scales the console (panel matrices and spots) to about 2.1 m long; the cabin camera uses `CABIN_FOV` (vertical, passed to `PlayerCamera`); couch centres move to 0.7 m; act 5 lines no longer focus. The figures are already 1.8 m tall with a 0.34 m helmet, so they are not scaled. The panel rows end up shorter than the real 0.9 m: keeping the console's own proportions was chosen over stretching the dials.
6. Line timing is checked in pure tests that run the event list through the radio queue with the reading times. Lines that would wait behind earlier ones are moved or the earlier line is shortened.

Task 6 notes: the flag line waited behind "We're off" and "Very quiet ride", and in play also behind "The EVA is progressing beautifully": the urgent liftoff count dropped the EVA line, which resolved its promise and queued the follow-up. Follow-ups in act 4 now run only in the phase that asked for them, and the flag line is said first, at the start of the fall. Air Boss now follows "Drogues.". Neil leaves the hatch as the last landing line starts (`neilMayGo`), so he climbs while Houston finishes; the landing talk itself still runs about 10 s past touchdown, which this task does not change.
